🚀 CÓMO USAR
═════════════════════════════════════════════════════════════════════════════

OPCIÓN 1: Migración Rápida (RECOMENDADA)
  
  1. En main.dart o Cloud Function:

     await MigrationUtils.runMigration();
  
  2. Espera 10-60 minutos
  3. ¡Listo! Todas las playas migradas

  floatingActionButton: MigrationButton(hidden: false),
  
  Resultado: Botón rojo 🔴 que abre diálogo de migración

🔧 MÉTODOS IMPLEMENTADOS
═════════════════════════════════════════════════════════════════════════════

1. migrateAllGoogleImagesToFirebase()
   ├─ Migra TODAS las playas en una pasada
   ├─ Retorna reporte completo
   └─ Uso: await FirebaseService.migrateAllGoogleImagesToFirebase();

2. migrateBeachImagesToFirebase(String beachId)
   ├─ Migra solo una playa
   ├─ Útil para testing
   └─ Uso: await FirebaseService.migrateBeachImagesToFirebase('1');

3. transferImageToFirebase(String googleUrl, String beachId, int index)
   ├─ Transfiere una imagen individual
   ├─ Uso bajo nivel
   └─ Uso: await FirebaseService.transferImageToFirebase(...);

4. MigrationUtils.runMigration()
   ├─ Interfaz amigable para ejecutar migración
   ├─ Incluye validaciones
   └─ Uso: await MigrationUtils.runMigration();

5. MigrationWidget
   ├─ Diálogo UI con progreso en tiempo real
   ├─ Logs detallados
   └─ Uso: MigrationButton(hidden: false)
